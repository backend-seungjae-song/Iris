# Iris 화면별 순차 점검표

## 목적

사용자가 판단·지시·확인·중단할 수 있도록 Iris의 방해 요소를 항목별로 점검하고 제거한다.
외부 서비스의 기능은 Iris MCP 또는 임의 MCP로 연결하며, Iris는 연결 과정·대상 표시·상태
보존·권한·복구를 관리한다.

## 점검 절차

1. 한 번에 한 항목만 점검한다.
2. 자동 검사로 코드 경로와 재현 조건을 준비하고, 사용자는 실제 화면에서 사용성과 결과를 확인한다.
3. 자동 검사를 통과해도 사용자가 화면을 확인하기 전에는 상태를 `완료`로 변경하지 않는다.
4. 문제가 발견되면 해당 항목에서 재현 → 테스트 → 수정 → 자동 재검증 → 사용자 재확인을 완료한 뒤 다음 항목을 점검한다.
5. 각 항목은 `screen_id / surface_id / state`로 식별한다.
6. 설치된 Iris는 현재 사용하는 업무 도구이므로, 재시작·교체·상태 변경이 필요하면 먼저 그 사실을 알린다.

상태는 `대기`, `점검 중`, `수정 중`, `재확인`, `완료`, `보류` 중 하나만 사용한다.

## 현재 상태

진행 상황은 이 표의 상태 열에 기록한다. `점검 중`인 항목은 항상 하나이며, 해당 항목을 완료한 뒤에만 다음 항목을 점검한다.

## 전체 화면 공통 합격 기준

각 점검 항목에서 아래 기준의 적용 여부를 모두 판정한다.

- 진입·이탈·화면 전환·키보드 이동·포커스 복귀
- 빈 상태·로딩·성공·오류·연결 끊김·오래된 상태·부분 성공
- 사용자가 보는 대상과 실제 조작 대상의 일치
- 확인·중단·취소·되돌리기·진행 상황·결과 표시
- 저장·재실행·스페이스 전환·이동·마이그레이션 뒤 복원
- Iris MCP와 임의 MCP의 대상·세션·그룹·권한·결과 인계
- 외부 서비스의 기존 기능 재사용·연결 실패·버전 불일치·교체 가능성
- 프로젝트·탭·계정·자격 증명 격리와 파괴적 동작 확인
- 앱·서버·webview 수명주기, 재연결·장애 복구·성능·진단

## keymap 편의 기능

| 항목 | 이름 | 점검 내용 | 상태 |
|---|---|---|---|
| keymap-01 | 단축키 목록 | 선언된 단축키 전체 표시·검색·적용 맥락·잠긴 항목의 이유 표시 | 대기 |
| keymap-02 | 재바인딩 | 키 등록 중 해당 단축키가 실행되지 않음·저장·창 두 개 동기·앱 재시작 유지 | 대기 |
| keymap-03 | 되돌리기·충돌 | 항목별·전체 기본값 복귀·같은 맥락 겹침 경고·잠긴 항목은 키 등록 불가 | 대기 |
| keymap-04 | 닫은 탭 | 최근 목록·복원·브라우저와 센터 탭 순서·분리 창에서 닫은 것 | 대기 |

```text
항목:

발견한 문제:
수정:
자동 검증:
사용자 재확인:
최종 상태:
```
