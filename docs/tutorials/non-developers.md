# 비개발자 튜토리얼: AI와 같은 화면을 보며 작업하기

웹페이지에서 설명이 필요한 문구를 직접 선택해 AI에게 질문하고, 답변을 원문과 비교해 보세요. 클릭해야 문제가 나타나는 경우에는 조작 순서를 기록해 전달할 수 있습니다. 이 과정에서 코드를 작성할 필요는 없지만 처음 설치할 때는 터미널을 사용합니다.

## 1. 설치하고 에이전트 준비하기

Apple Silicon Mac과 macOS 14 이상이 필요합니다. **이 Mac에 관하여**에서 칩과 macOS 버전을 확인하세요. Intel Mac과 Windows는 지원하지 않습니다.

`⌘Space`를 누르고 “터미널”을 검색해 여세요. 다음 명령을 한 줄씩 붙여넣고 Enter를 누릅니다.

```bash
git clone https://github.com/backend-seungjae-song/Iris.git
cd Iris
./setup
```

첫 명령은 설치 파일을 받을 `Iris` 폴더를 만듭니다. 두 번째 명령으로 그 폴더에 들어가고, 세 번째 명령으로 설치를 시작합니다. Git 설치 안내가 나타나면 설치를 마친 뒤 첫 명령부터 다시 실행하세요.

설치 중 실행할 명령과 확인 질문이 표시됩니다. Node.js나 herdr 준비에 실패하면 표시된 안내를 따라 설치한 뒤 다시 실행하세요. 준비 상태만 확인할 때는 `./setup --check`를 사용합니다.

설치가 끝나면 응용 프로그램 폴더에서 Iris를 열 수 있습니다. 에이전트 연결에도 사용하는 `Iris` 폴더는 남겨 두세요.

Claude Code 또는 Codex는 별도로 설치하고 로그인해야 합니다. `./setup`에서는 설치되어 있는 에이전트에 Iris 도구를 연결할지 묻습니다. 에이전트를 나중에 설치했다면 `Iris` 폴더에서 `./setup`을 다시 실행하세요. 이때 Iris 앱도 다시 빌드됩니다.

## 2. 대화할 에이전트 선택하기

왼쪽 **작업 → SPACES**에서 작업할 스페이스를 선택하세요. 스페이스는 프로젝트별로 파일과 작업을 구분하는 단위입니다. 처음이라면 **SPACES** 옆의 `+`를 누르고 작업할 폴더의 경로를 입력합니다.

오른쪽 터미널 탭의 `+`에서 **새 탭 — Claude 세션** 또는 **새 탭 — Codex 세션**을 선택하세요. 로그인 안내가 나타나면 완료한 뒤 왼쪽 **AGENTS**에서 해당 세션을 선택합니다.

화면에서 고른 대상은 이 세션으로 전달됩니다. 여러 에이전트를 사용한다면 지금 대화할 세션이 선택되어 있는지 확인하세요.

## 3. 함께 볼 페이지 열기

Iris 브라우저에서 새 탭을 열고 확인할 페이지의 주소를 입력하세요. 처음에는 로그인이나 결제가 필요 없는 공개 안내 페이지로 연습할 수 있습니다.

예를 들어 행사 안내를 읽는다면 신청 조건이나 취소 안내가 있는 부분으로 이동하세요. 업무용 계정이 필요한 페이지에서는 브라우저 프로필을 먼저 확인하고 직접 로그인합니다.

## 4. 문구를 선택해 질문하기

`⌘⇧E`를 눌러 요소 지목 모드를 켜고 질문할 문구 위로 마우스를 옮기세요. 표시된 영역이 원하는 부분인지 확인한 뒤 클릭합니다.

선택한 대상의 정보가 오른쪽 에이전트 터미널에 전달되었는지 확인하고 질문을 입력하세요.

![선택해서 전달한 영역을 표시한 실제 웹페이지](../images/element-pick.png)

이미지는 Iris 공개 저장소에서 지목한 영역을 표시한 예시입니다. 실습에서는 질문할 문구를 선택하세요.

> 선택한 안내에서 신청 조건과 취소 조건을 정리해 줘. 페이지에 없는 내용은 확인되지 않았다고 적어 줘.

답변에 나온 조건을 원문과 비교하세요. 수정할 웹페이지를 개발자와 함께 작업하고 있다면 “선택한 문구를 처음 방문한 사람도 이해할 수 있게 바꾸고 싶어. 대체 문구 세 개를 제안해 줘”처럼 요청할 수 있습니다.

모양이나 위치를 설명하려면 `⌘⇧D`로 스케치를 열어 표시하세요.

## 5. 문제가 나타나는 과정 전달하기

“검색한 뒤 화면이 멈춘다”처럼 조작 순서가 필요한 문제는 기록으로 전달할 수 있습니다.

1. 문제가 발생하기 전 화면으로 이동합니다.
2. `⌘⇧A`를 눌러 기록을 시작합니다.
3. 검색어 입력, 버튼 클릭 등 문제가 발생하는 조작을 수행합니다.
4. 다시 `⌘⇧A`를 눌러 기록을 끝냅니다.
5. 에이전트 터미널에서 전달된 기록을 확인하고 기대한 결과와 실제 결과를 적습니다.

> 검색어를 입력하고 검색 버튼을 눌렀어. 검색 결과가 나와야 하는데 로딩 표시가 계속 남아 있어. 전달된 순서로 확인해 줘.

로그인 정보나 결제 정보가 필요 없는 과정으로 연습하세요. 이 기능은 조작 내역을 전달하며 동영상 파일을 만들지는 않습니다.

## 6. 결과 확인하고 다음 작업 이어가기

에이전트가 설명한 내용을 원문과 비교하고, 수정을 요청했다면 브라우저에서 같은 작업을 다시 수행하세요. 선택한 문구와 질문이 같은 세션에 전달되고 답변의 근거를 확인했다면 첫 작업을 마친 것입니다.

다른 작업을 시작할 때는 해당 스페이스와 에이전트 세션을 선택하세요. 필요한 결정 사항은 **메모**에 남길 수 있습니다.

## 막혔을 때

| 증상 | 확인할 내용 |
|---|---|
| 터미널이나 SPACES가 비어 있음 | 설치 폴더에서 `./setup --check`를 실행해 herdr 준비 상태를 확인하세요. |
| AI 세션이 시작하지 않음 | 선택한 Claude Code 또는 Codex의 설치와 로그인을 확인하세요. |
| 선택한 요소가 전달되지 않음 | AGENTS에서 대화할 세션을 선택했는지 확인하세요. |
| 원하는 영역이 선택되지 않음 | 마우스를 조금 옮겨 강조 영역을 확인하거나 화면 스케치를 사용하세요. |
| 단축키가 다르게 작동함 | **설정 → 단축키**에서 현재 지정된 키를 확인하세요. |
| AI가 다른 탭을 볼 수 없다고 함 | 전달하려는 탭으로 이동해 해당 세션에 직접 지목하세요. |
