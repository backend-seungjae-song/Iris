# Herdr 세션에서 Paseo 대화 화면 사용하기

Herdr 터미널에서 평소처럼 CLI를 실행하고 Iris의 **Spaces · Agents**에서 해당 세션을 선택하세요. 같은 폴더에서 에이전트를 두 개 실행했을 때도 패널을 각각 선택할 수 있습니다. 대화 보기를 닫거나 다른 패널로 이동해도 실행 중인 CLI에서 작업을 계속할 수 있습니다.

## 어떤 설정을 바꿀 수 있나요?

Herdr에서 식별한 세션에 Paseo 제공자가 연결할 수 있으면 대화 화면에서 그 세션의 설정을 바꿀 수 있습니다. 제공자는 각 CLI와 통신하는 Paseo 플러그인입니다. 모델, 모드, 권한과 Speed 중에서 표시되는 항목은 제공자와 현재 세션에 따라 다릅니다.

예를 들어 Codex에서는 실행 중인 스레드를 제어할 수 있는 Codex app-server 연결이 필요합니다. 같은 프로젝트의 다른 스레드에 연결해 설정을 바꾸는 일을 막기 위해 패널과 스레드가 일치하는지 확인합니다. 기존 CLI에서 제어 연결을 제공하지 않으면 대화 화면에 표시되는 해당 패널의 CLI 화면에서 직접 설정을 바꾸세요.

## Iris에서 사용하는 Paseo 코드

Iris 안에서 대화할 때 별도로 Paseo 앱을 실행할 필요가 없습니다. Iris는 Paseo 릴리스에서 대화 UI를 빌드하고 해당 릴리스의 제공자 정의와 플러그인을 읽습니다. 새 릴리스의 화면을 빌드하는 데 실패하면 이전 빌드를 계속 사용합니다.

- 대화 화면과 설정을 수정할 때는 Paseo 컴포넌트를 불러오는 진입점과 현재 세션의 상태를 전달하는 코드를 확인하세요. [화면 진입점](../server/paseo-ui/entry/iris-chat-entry.tsx)
- 제공자 지원 범위를 확인할 때는 해당 릴리스의 내장 플러그인과 ACP 제공자 목록을 확인하세요. 목록에 있는 제공자라도 실행 중인 CLI가 지원하는 연결과 설정만 사용할 수 있습니다. [제공자 목록 생성 코드](../server/paseo-ui/managed-provider-catalog.js)
- 패널이 바뀌거나 닫힐 때는 구독을 해제하고 새로 선택한 세션의 상태와 기록을 표시합니다. [대화 보기 연결 코드](../web/js/agentchat/boot.js)

같은 폴더에서 두 패널을 열고 한쪽의 설정을 바꿔 보면 연결을 확인할 수 있습니다. 설정을 바꾼 세션의 다음 요청에만 변경이 적용되어야 합니다.
