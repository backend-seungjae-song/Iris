# 확인 탭 알림

AI 세션이 확인할 보고서나 화면을 Iris 탭에 띄우고, 사람에게 그 탭으로 가는 알림을 보내는 방법이다.
사람이 다른 일을 하다가 알림의 [그 탭으로]를 누르면 그 스페이스의 그 탭이 열린다.

## 호출 순서

1. 확인할 화면을 탭에 연다. `browser_new_tab`에 `url`을 준다. `https://` 또는 `file:///절대/경로.html`을 쓸 수 있다.
   - 탭은 뒤에 열리므로 사람이 보던 화면은 바뀌지 않는다.
   - 결과의 `data.handle`(예: `@iris-tab-a1b2c3`)을 다음 단계에 쓴다.
2. `notify`로 알린다.

```json
{ "level": "info", "title": "보고서 초안 확인", "body": "3장 표를 봐 주세요", "tab": "@iris-tab-a1b2c3", "review": true }
```

| 입력 | 필수 | 뜻 |
|---|---|---|
| `level` | 예 | `ok`·`info`·`warn`·`err` |
| `title` | 예 | 60자까지 |
| `tab` | review 일 때 예 | 1단계의 handle. 이 세션이 쓸 수 있는 탭이어야 한다 |
| `review` | 아니오 | `true`면 확인 탭 알림 |
| `body`·`detail`·`key` | 아니오 | 본문 300자, 자세한 내용 2000자, 같은 알림을 고칠 키 |

## 반환

- 성공: `{ ok: true, data: { id, shown, tab } }`
  - `shown`이 `"both"`면 Iris 창이 앞에 없어서 macOS 알림도 띄웠다. `"app"`이면 Iris 안의 알림만 띄웠다.
  - `tab`은 알림이 가리키는 탭의 handle이다.
- 실패: `{ ok: false, error }`
  - `review 알림은 확인할 화면을 띄운 tab이 필요합니다.`: `tab`이 없다.
  - `관련 탭을 찾을 수 없습니다.`: handle에 맞는 탭이 없거나 둘 이상이다.
  - `이 세션이 쓸 수 있는 탭이 아닙니다.`: 다른 스페이스나 다른 그룹의 탭이다.
  - `tab과 device는 하나만 적어 주세요.`

## 사람 쪽 동작

- 알림은 사람이 닫을 때까지 남는다. 일반 `info` 알림처럼 4초 뒤에 사라지지 않고, 다른 알림과 합쳐지지도 않는다.
- macOS 알림을 누르면 Iris 알림 목록의 그 알림으로 간다. 탭은 아직 바뀌지 않는다.
- [그 탭으로]를 누르면 그 탭이 있는 스페이스로 옮긴 뒤 그 탭을 연다.
- 그 사이 탭이 닫혔으면 이동하지 않고 단추가 "탭이 닫혀 이동할 수 없음"으로 바뀐다.
- 이동하거나 알림을 닫은 결과는 호출한 세션에 돌아가지 않는다. 승인이나 검수 완료로 쓰지 않는다. 확인 결과는 사람이 세션 대화에서 알려 준다.

## 한계

- 알림 목록은 접힌 상태에서 가장 최근 알림 하나만 보여 준다. 확인 알림이 여럿이면 "알림 펼치기"를 눌러야 앞의 것이 보인다.
- 폰 원격 화면은 이 알림을 받지 않는다.

검사: `test/notify-review.mjs`(서버), `test/notice-review-ui.mjs`(알림 목록 화면).
