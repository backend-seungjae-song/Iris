# Iris 휴대전화 앱

Android 휴대전화에서 Mac의 Iris 세션을 확인하고 메시지를 보낼 수 있습니다. 에이전트의 허용 요청과 질문에 답하거나 실행을 중지할 수 있으며, Mac에서 허용한 기능에 따라 터미널·브라우저·Git 화면도 열립니다. 현재 앱은 소스에서 직접 실행합니다. Android 11(API 30) 이상이 필요합니다.

## 준비와 연결

1. [Mac용 Iris](../README.md#설치하기)를 설치하고 실행합니다. Mac과 휴대전화에 Tailscale을 설치해 같은 계정으로 로그인합니다.
2. Mac의 Iris에서 **원격**을 엽니다. 화면의 **휴대폰 연결 순서**를 따라 접속 PIN을 정하고 Tailscale과 원격 제어를 켭니다.
3. 휴대전화에 Flutter 개발 환경과 Android SDK를 준비합니다. 이 폴더에서 `flutter pub get`을 실행한 뒤 연결된 Android 기기에 `flutter run`으로 앱을 설치합니다.
4. Mac의 **원격 → 기기 추가**에서 QR 코드를 띄웁니다. 휴대전화 앱의 **QR 코드 스캔**으로 읽고, 휴대전화에 나온 확인 숫자를 Mac에 입력합니다.
5. 휴대전화에서 Mac을 선택하고 접속 PIN을 입력합니다. PIN은 Mac의 Iris에서 바꿀 수 있습니다.

Mac의 **원격** 화면은 어느 단계가 남았는지 현재 상태에 맞춰 표시합니다. 연결이 끊겼다면 Mac과 휴대전화의 Tailscale 상태, 원격 제어 켜짐 상태, PIN 안내를 그 화면에서 확인하세요.

휴대전화 앱은 등록된 기기 키와 Mac의 인증서를 확인해 연결합니다. PIN을 정하거나 바꾸는 화면은 Mac에 있으며, 휴대전화에 입력한 PIN은 저장하지 않습니다. 원격 연결과 자격증명 처리 범위는 [보안 안내](../SECURITY.md)에 적었습니다.
